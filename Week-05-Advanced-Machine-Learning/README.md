# House Price Prediction Using Advanced Machine Learning

## Project Overview

This project compares multiple machine learning algorithms for predicting house prices. A baseline Linear Regression model was developed and compared with Decision Tree, Random Forest, and Gradient Boosting models. Hyperparameter tuning was performed using GridSearchCV to improve model performance.

## Dataset

House Price Prediction Dataset

## Models Used

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- Tuned Random Forest

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Results

Gradient Boosting achieved the best performance with:

- MAE: 959,749
- RMSE: 1,299,386
- R² Score: 0.6660
